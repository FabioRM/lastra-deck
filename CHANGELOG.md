# Lastra changelog

Completed items from the former TODO, grouped by the section that tracked them. Each entry keeps its original wording, priority, utility rating, and catalog ID. Open work and the priority and ID scheme are described in the [roadmap](ROADMAP.md).

Entries grouped under **0.2.1** record the completed work through the first reviewed source release.

## 1.0.0

- Arrange Settings in the same order as the deck views: Deck keys, Dashboard, Stats, Feeds, Tools, then OBS. Display and System sit under Setup.
- Keep history, watchlist, agent access, diagnostics, updates and profile files on the page. Settings no longer opens a system menu.

## 0.2.10

- Run a key's release action when a press ends or is cancelled, including after the finger leaves the key.
- Add a Feeds view for weather, stock quotes and currency rates. The sky follows the location's sunrise and sunset, and the moon shows the current phase. Today's low and high appear with the place.
- Choose the activity profile, navigation, and deck organization in Display settings instead of a system menu.
- Keep one clock in the top-left corner while switching among Dashboard, Stats, and Feeds.
- Export the saved deck settings and activity profiles as one configuration file. Tokens and service accounts stay on this PC.
- Deepen the daily Windows packs for Chrome, Edge, Firefox, Brave, Visual Studio Code, Windows Terminal, Spotify, GIMP, VLC, Visual Studio and Paint.NET with documented shortcuts.
- Add MusicBee, using the default hotkeys recorded from a clean install on the MusicBee forum. [Shortcut packs](docs/shortcut-packs.md)
- Put Cursor's published Agent, chat, and Tab shortcuts on the deck, with the inherited editor chords and Design Mode in the Agents Window. [Cursor shortcuts](docs/cursor-shortcuts.md)

## 0.2.9
