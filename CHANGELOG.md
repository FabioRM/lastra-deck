# Lastra changelog

## Unreleased

- Add nine Linux profiles with 82 shortcut entries for Slack, Signal Desktop, Discord, Telegram Desktop, mpv, FileZilla, Geany, DBeaver and Wireshark.

## 0.2.8

- Ship the Linux x86-64 `.deb`, AppImage and GNOME Shell extension. The Deck follows the foreground app and sends shortcuts on X11, GNOME, KDE Plasma and Hyprland. [Linux setup](docs/linux-deck.md)
- Ship 37 Linux profiles with 523 shortcut entries, including Konsole, Dolphin, LibreOffice, Blender, QGIS, Audacity, Kate, Zed and six JetBrains IDEs.
- Expand the Windows and installed-web catalog to 446 apps, alongside nine edition and editor packs. [Specialist shortcuts](docs/specialist-shortcuts.md)

## 0.2.7 · 2026-11-21

- Expand automatic shortcut coverage to 420 Windows and installed web apps, plus nine edition and editor packs. Add Altium Designer and Simulink, and extend SOLIDWORKS, KiCad, and MATLAB. [Engineering shortcuts](docs/engineering-shortcuts.md)
- Keep one default pair of Chrome tab controls. Reuse Back and Forward on the persistent bar when those controls already apply to Chrome.
- Remove the redundant system volume buttons from Home and compact its shortcuts. Cut, Copy, Paste, Undo, and Redo keep the final five cells on every screen.
- Show Deck notifications above the Home clock without moving the clock, shortcuts, or mixer.

[Windows downloads](https://github.com/FabioRM/lastra-deck/releases/tag/v0.2.7) · [Project site](https://fabiorm.github.io/lastra-deck/)

## 0.2.6 · 2026-11-21

- Automatic shortcut packs fill each screen before opening another. The default 8×3 grid fits 19 app shortcuts and five fixed editing keys per screen. New custom layouts start from one compact shortcut list.
- The shortcut library covers 342 Windows and installed web apps, plus five packs for specific editions or window variants. [Shortcut packs](docs/shortcut-packs.md)
- Commands that require a specific editor, panel, canvas, or browser app surface check the current Windows focus before sending input.
- Refine Tools and Pomodoro controls and expand the hardware readings available in Stats.

[Windows downloads](https://github.com/FabioRM/lastra-deck/releases/tag/v0.2.6) · [Project site](https://fabiorm.github.io/lastra-deck/)

## 0.2.5 · 2026-11-20

- Enlarge the Tools panel and its touch controls. Close it with the red × in the top-right corner.
- Show a Pomodoro break full-screen on the XENEON EDGE. The red × returns to the previous view while the timer continues.
- Configure multiple shortcut pages per app. Add, reorder, hide, or remove commands. New packs cover Notepad, Paint, and SumatraPDF.
- Align the Tools, Emoji, and page lock buttons with the Deck Keys grid. Refresh the site screenshots and animations.
- Resize and reorder Stats cards, combine up to four readings on one chart, and show supported CPU power, clock, voltage, and current readings.
- Extend the review flow for local agent requests and PowerToys workspaces.

[Windows downloads](https://github.com/FabioRM/lastra-deck/releases/tag/v0.2.5) · [Project site](https://fabiorm.github.io/lastra-deck/)

## 0.2.4 · 2026-11-20

- First public Windows x64 installer. Installs per user and receives updates from GitHub Releases.
- Deck Keys supports larger buttons and configurable global keyboard shortcuts. The deck and editor support English and Italian.
- The redesigned profile editor groups pages, keys, and actions. New deck palettes and custom accent colors are available.
- Stats adds reorderable and resizable overview cards, dedicated chart and readings views, and power in watts alongside system load when available.
- Quick decision widgets offer a coin flip, a die roll, and a pick from a list. Reviewed MCP actions can open saved Windows workspaces and hand off to configured PowerToys workspaces.

[Windows downloads](https://github.com/FabioRM/lastra-deck/releases/tag/v0.2.4) · [Project documentation](README.md)
