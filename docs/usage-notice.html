Usage and warranty notice

Downloads and backups

Download installers from the official Lastra release page and compare the file’s SHA-256 checksum with the published value before running it. An unsigned Windows build may trigger a publisher or reputation warning. Keep your operating system’s protections enabled. Export a copy of your configuration before updating or importing a profile.

Macros and integrations

Lastra actions can send keystrokes, open files or applications, change audio settings and control connected services. Review shared profiles and macros before importing or running them. Test new actions in a safe context with the intended application in focus. Enable third-party integrations only when needed and review the data and permissions they use. Remove sensitive details from diagnostics before sharing them.

Avvertenze d’uso e garanzia

Download e copie di sicurezza

Scarica gli installer dalla pagina ufficiale delle release di Lastra e confronta l’hash SHA-256 del file con quello pubblicato prima di eseguirlo. Una build Windows senza firma può mostrare un avviso sul produttore o sulla reputazione del file. Mantieni attive le protezioni del sistema. Esporta una copia della configurazione prima di aggiornare Lastra o importare un profilo.

Macro e integrazioni

Le azioni di Lastra possono inviare pressioni di tasti, aprire file o app, modificare l’audio e controllare servizi collegati. Controlla profili e macro condivisi prima di importarli o avviarli. Prova le nuove azioni in un contesto sicuro con l’app di destinazione in primo piano. Attiva le integrazioni di terze parti quando ti servono e verifica quali dati e permessi usano. Rimuovi i dati sensibili prima di condividere la diagnostica.
