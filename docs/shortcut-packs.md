# Windows shortcut packs

In Deck Keys, Lastra uses the focused app's built-in pack when no custom page matches. The Main activity uses the VS Code pack or the actual browser's pack when the corresponding app takes focus. Custom pages keep their matching rules and priority. Each browser pack uses that browser's native tab bindings.

When an automatic pack has additional reviewed commands, its **Quick actions** appear first and later sheets group the extra commands by purpose. Use the page arrows or swipe to move through the groups. Each sheet reserves the same five editing positions. A command whose app mode, layout, or language cannot be verified shows its availability reason.

In the profile editor, choose **Shortcut packs** to search offline by action, alias, or chord and filter by app, platform, and context. Select a result to see its source, exact variant, and any reason it is unavailable. **Copy to this page** places one action in the first free slot. **Copy pack to a new page** links app IDs or executable aliases that are free in the profile. Copied actions preserve their app, platform, layout, language, and mode requirements. Unresolved bindings stay in the catalog for review. Closing, permanent deletion, ending a call, and sending commands require confirmation.

For a supported single chord, type the replacement or select **Capture**, then choose **Set local override** and save the profile. The override applies to that action in the matching app and variant, including eligible automatic controls. Existing copied actions keep their saved bindings. **Reset to reviewed default** clears the override for future copies and automatic controls. Catalog revisions preserve overrides when the action and its variant requirements stay the same. If the catalog changes those requirements, the saved override stays in the profile and waits for a matching variant.

The starter packs cover Chrome, Edge, Firefox, Brave, File Explorer, VS Code, Windows Terminal, Excel, Word, PowerPoint, classic and new Outlook, Teams, Discord, and Spotify. Packs preserve a control's position when the binding is unavailable. Explorer's new tab requires a Windows 11 build with tabs. Punctuation bindings for the VS Code terminal and Excel AutoSum require the US keyboard layout. Set **Office shortcut language** to the application's verified language for localized Office shortcuts. Teams meeting controls and the new Outlook **New message** shortcut require known meeting or Mail context, respectively. Spotify **Play or pause** waits for the targeted Windows media session to report the new playback state.

The header shows the installed app icon when Windows supplies one. Each key has a Lucide action icon, and the editor shows adjacent commands with their icons and bindings for comparison. Hover over a key or use a screen reader to hear its shortcut and any availability reason. Use `npm start -- --preview=pack.png --preview-pack=edge` to render a pack on sample data, and add `--preview-portrait` for a vertical preview.

The **Adobe Photoshop** pack matches `Photoshop.exe` and `Adobe Photoshop.exe`. It covers selection, transforms, layer grouping, Curves, panels, zoom, and Save for Web. Lastra suspends these bindings when Windows reports a dialog or a text field. Use **Keyboard shortcuts** in Photoshop to verify a custom keymap, then edit a copy of the pack in Lastra. Photoshop on the web has its own bindings. The Windows classifier has tests for workspace, modal, and text-field states. Photoshop's custom canvas text editing still needs a live check. [Adobe desktop shortcuts](https://helpx.adobe.com/content/dam/help/en/photoshop/using/default-keyboard-shortcuts/photoshop-keyboard-shortcuts.pdf) · [View Photoshop shortcuts](https://helpx.adobe.com/uk/photoshop/desktop/get-started/settings-and-preferences/view-keyboard-shortcuts.html) · [Adobe web shortcuts](https://helpx.adobe.com/uk/photoshop/web/get-set-up/preferences-and-settings/keyboard-shortcuts.html)

Photoshop workspace detection requires Windows to report stable focus in the foreground window. A changing focus, layout, menu, dialog, or native text caret blocks workspace shortcuts. Teams meeting and new Outlook Mail shortcuts stay unavailable until their specific modes can be verified. Windows package identities identify the app. [GetGUIThreadInfo](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-getguithreadinfo) · [GetAncestor](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-getancestor) · [UI Automation properties](https://learn.microsoft.com/windows/win32/winauto/uiauto-automation-element-propids)

Google Docs, Sheets, Slides, Canva, Miro, and Photoshop on the web require a verified editing surface for their document or canvas commands and fixed editing keys. These controls stay unavailable on an app home screen or when Lastra cannot verify the editing surface. Saved copies of the original starter chords use the same mode check.

## Keyboard notation

- `Ctrl+/`, `Alt+=`, `Ctrl++`, and `Ctrl+char:colon` use the character produced by the active Windows layout. Lastra adds Shift when the layout requires it. For example, `/` is a single key in US and Shift+7 in Italian.
- `Ctrl+slash` and `Ctrl+vk:BF` use the Windows virtual key. Existing named punctuation shortcuts retain their virtual keys.
- `Ctrl+scan:29` targets a physical key by its hexadecimal scan code. `scan:E04D` is an extended scan code.

The editor preserves the source notation on copied shortcuts. If Windows cannot map a character to one key, or the character needs AltGr or another Ctrl/Alt combination, the deck shows the reason and leaves the command unavailable. Italian (142) uses AltGr for the backquote. Choose a virtual key or scan code when the target application's documentation specifies one. The profile editor can simulate these three layouts. [US layout](https://learn.microsoft.com/en-us/globalization/keyboards/kbdus_7) · [Italian layout](https://learn.microsoft.com/en-us/globalization/keyboards/kbdit) · [Italian (142) layout](https://learn.microsoft.com/en-us/globalization/keyboards/kbdit142) · [VkKeyScanExW](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-vkkeyscanexw)

## Offline catalog

The public catalog contains bindings from vendor documentation and separate references from licensed sources. [Catalog redistribution review](catalog-redistribution.md) · [Bundled catalog](../profiles/shortcut-catalog.json)

The ledger records app-scoped action IDs and stable binding IDs. Each variant records its platform, host platform, edition, app version, Windows build, language, layout, mode, source URL and revision, and verification status, method and date. A `null` field marks evidence that is still unknown. The 62 variants cover 49 actions in six apps. There are 51 Windows and 11 web variants, including nine Google Docs variants for the web editor on a Windows host. Documentation establishes 56 candidates, five remain ambiguous, and one has an unknown binding. [Google Docs keyboard shortcuts](https://support.google.com/docs/answer/179738) · [Coverage report](../profiles/shortcut-catalog.json)

In **Shortcut packs**, ambiguous entries show why they are unavailable. The Italian Excel guide assigns `Ctrl+C` to Copy and Italic and `Ctrl+S` to Save and Underline. These entries stay available for review. Excel `Ctrl+A` can select a data region before the entire worksheet. Teams variants record desktop or web and the call context, and the Personal edition keymap remains unknown. A VS Code chord with more than one stroke stays visible as a sequence. C14 tracks hands-on validation. [Italian Excel guide](https://support.microsoft.com/it-it/accessibility/excel/keyboard-shortcuts-in-excel) · [English Excel guide](https://support.microsoft.com/en-us/accessibility/excel/keyboard-shortcuts-in-excel) · [Teams keyboard shortcuts](https://support.microsoft.com/en-us/accessibility/teams/keyboard-shortcuts-for-microsoft-teams) · [VS Code Windows keymap](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-windows.pdf)

The **Keyboard shortcuts** entry for VS Code can be assigned as the reviewed `Ctrl+K` then `Ctrl+S` sequence. Lastra releases each chord before sending the next and rechecks the foreground window and US layout between the steps. Alternative chords are separate variants. Sequences that depend on holding a modifier across strokes remain reference entries. [VS Code default keybindings](https://code.visualstudio.com/docs/reference/default-keybindings)

Desktop packs cover 31 inventory apps. The additions cover Acrobat, After Effects, Arc, Blender, Cursor, DaVinci Resolve, Figma, Illustrator, IntelliJ IDEA, Lightroom Classic, Notepad++, Notion, Obsidian, Premiere, Slack, Sublime Text, gVim, and Zoom. Installed web app packs cover Google Docs, Sheets, Slides, Gmail, Meet, YouTube, Trello, Jira Cloud, Asana, Canva, Linear, and Miro. Photoshop on the web has a separate pack. The packs ship with common manifest IDs where available. When an installation uses a different ID, copy its `manifest_id` from `chrome://web-app-internals` or `edge://web-app-internals`, attach it in **Shortcut packs**, and save the profile. Commands that require a meeting, player, or editor mode stay unavailable until Lastra can verify that context. Automated tests cover the known YouTube manifest ID, app switching, custom page priority, and tenant or path validation. The Windows live keymap and device matrix is tracked in C14.

## Fixed editing keys

The standard Deck Keys grid has 24 positions across three rows of eight. Its final five positions hold **Cut**, **Copy**, **Paste**, **Undo**, and **Redo**. Equivalent shortcuts appear once, and the other 19 positions hold quick actions and widgets. Use the page arrows or swipe horizontally to reach any overflow. The five buttons stay on the bottom row when you change pages or rotate the deck. Compact profiles and the editor's live preview use the same arrangement with at least five columns. Lastra preserves the original keys and widget layouts in the profile.

The keys follow the current verified foreground window. A contextual page whose target has moved out of the foreground keeps the five buttons visible and unavailable. Lastra uses reviewed variants where the active app differs from the Windows editing defaults. Adobe Illustrator, Premiere, and Photoshop use `Ctrl+Shift+Z` for Redo. Reviewed language, keyboard-layout, and app-mode requirements still apply. [Windows shortcuts](https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows) · [Illustrator](https://helpx.adobe.com/illustrator/desktop/get-started/preferences-and-settings/default-keyboard-shortcuts-for-illustrator.html) · [Premiere](https://helpx.adobe.com/premiere/desktop/get-started/keyboard-shortcuts/default-keyboard-shortcuts.html) · [Photoshop Undo and Redo](https://helpx.adobe.com/photoshop/desktop/get-started/set-up-toolbars-panels/use-undo-redo-commands.html)

Windows Terminal uses its verified Paste shortcut. Its Copy chord can reach the shell without a text selection, so the fixed Copy button requires verified selection. Lastra keeps Cut, Undo, and Redo unavailable in the terminal. Select an unavailable button's indicator to read the reason. [Windows Terminal actions](https://learn.microsoft.com/en-us/windows/terminal/customize-settings/actions)
