# IntelliJ IDEA Windows keymap coverage

The profile editor’s **Shortcut packs** lists IntelliJ IDEA’s **Windows default**, **Emacs for Windows**, and **Sublime Text for Windows** as separate references. Search by JetBrains action ID, action name, chord, or component family. These references also appear in offline MCP search. The existing IntelliJ IDEA starter remains separate.

The definitions come from JetBrains’ public IntelliJ Platform source at release `idea/2026.2.3`, commit `8062c061ff33e22041d9f1844db5b8b8a6b5e4d7`. That release’s shared Windows descriptor declares 426 actions, including 447 keyboard sequences, 14 pointer inputs, two double presses and 15 actions with empty bindings. The reference preserves ordered strokes, distinguishes numeric keypad keys, and retains action IDs with their exact case. The shared descriptor’s X11 clipboard entry has its own platform note. The English titles come from the same release’s action resources where available. [JetBrains Windows keymap help](https://www.jetbrains.com/help/idea/reference-keymap-win-default.html) · [JetBrains raw keymap guidance](https://support.jetbrains.com/hc/en-us/articles/40249348815378-List-of-keyboard-shortcuts) · [Coverage ledger](../profiles/intellij-idea-keymaps.json)

Emacs and Sublime Text build on the Windows descriptor. A child declaration replaces the parent action’s inputs, including an explicit empty assignment. Find Action uses Ctrl+Shift+A in Windows default, Esc then X or Alt+X in Emacs, and Ctrl+Shift+P in Sublime Text. Search Everywhere uses a double press of Shift. Context families help locate the corresponding action. Where several actions share a chord, check the focused pane and which action the IDE enables. IntelliJ IDEA Classic has a separate reference to the keymap selection. [JetBrains keymap implementation](https://github.com/JetBrains/intellij-community/blob/8062c061ff33e22041d9f1844db5b8b8a6b5e4d7/platform/platform-impl/src/com/intellij/openapi/keymap/impl/KeymapImpl.kt) · [Available JetBrains keymaps](https://www.jetbrains.com/help/idea/configuring-keyboard-and-mouse-shortcuts.html)

No installed IntelliJ IDEA build or selected keymap was found on the inspected Windows host. Edition-specific and plugin-added actions, active custom mappings, keyboard layout and real editor, popup or tool-window delivery remain open. The raw descriptor data covers the declared IntelliJ Platform keymaps. Compare **Settings → Keymap** in the target IDE before assigning a deck button.
