# 30 nuove app per creatività, produttività e strumenti specializzati

Lastra copre 412 applicazioni. Questo aggiornamento aggiunge 199 scorciatoie per 20 app desktop Windows e 10 app web installate. Le note nell’editor indicano il pannello, la selezione o il layout richiesto dal singolo comando. [Lotto precedente](workspace-shortcuts.md) · [Guida al Deck](shortcut-packs.md)

Per Retool Classic Apps, associa in **App shortcuts** l’ID manifesto del dominio del tuo team. Frame.io usa l’indirizzo `next.frame.io` di V4. Installa OpenStreetMap iD dal percorso `/edit` per usare il pacchetto di modifica della mappa.
