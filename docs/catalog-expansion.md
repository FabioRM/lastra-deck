# 50 nuove app e 35 pacchetti ampliati

Questo aggiornamento ha portato il catalogo a 330 applicazioni con 432 tasti aggiunti ai pacchetti esistenti e 238 tasti per le nuove app. [Prime 200 app](200-applications.md) · [Successive 80 app](additional-applications.md) · [Altre 12 app](authoring-shortcuts.md)

In **Deck Keys**, usa le frecce o scorri orizzontalmente per passare alle pagine tematiche. Puoi trovare e copiare i nuovi comandi in **App shortcuts** nell’editor, anche quando hai già personalizzato le pagine di un’app.

I pacchetti web si attivano per le app installate dal browser. Per Home Assistant Cloud e Grafana Cloud associa nel profilo l’ID manifesto del tuo dominio. Le guide riportano i tasti predefiniti. Alcune azioni richiedono un pannello attivo, un layout di tastiera specifico o l’attivazione delle scorciatoie nelle impostazioni dell’app.

Lastra usa Windows UI Automation per abilitare le azioni protette quando riconosce l’editor o la riunione attiva. [Guida ai pacchetti di scorciatoie](shortcut-packs.md)
