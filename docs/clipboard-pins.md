# Pinned clipboard

Open **Apps → Pinned clipboard**. Copy text in Windows, then select **Capture clipboard text** on the deck. Check the preview, give it a name, and select **Pin text**. The preview contains the text captured when you pressed the button, even if the Windows clipboard changes while you review it.

Select a saved name to preview its text. Choose **Copy to clipboard** to recall it, then paste in the destination app. **Move up** and **Move down** change the order. **Remove pin** asks you to confirm removal. The library holds up to 24 pins of 4,096 characters each.

Lastra stores protected pin text and the saved order in its local application data using Windows encryption when available. When storage protection is unavailable, new pins remain available for the current session. View-only mode shows saved names and keeps clipboard actions disabled.
